# Gate Decision Ledger V1

This artifact records:
- lifecycle state used
- current gate observations from legacy blended evaluation
- inclusion and exclusion decisions for authorization and economic-health verdicts
- final blocking decisions per action domain

No gate may implicitly move between action domains without an explicit registry change.
