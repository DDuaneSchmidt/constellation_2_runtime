# manual_execution_event.v1

`manual_execution_event.v1` records what the operator manually entered in IB paper.

It captures symbol, direction, instrument type, side, quantity, order type, actual entry price, entered stop price, stop order type, optional IB identifiers, execution time, deviation from Aegis plan, and operator notes.

This artifact does not submit orders and does not depend on broker transmit or Aegis IB automation.
