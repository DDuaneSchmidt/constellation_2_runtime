# edge_cluster.v1

`edge_cluster.v1` groups sleeve hypotheses and candidate expressions into portfolio-level edge clusters.

Sleeves produce hypotheses and candidate expressions. Aegis clusters edges. Governance acts on edge clusters and portfolio exposure. The EOD report presents the manual execution queue.

Clusters include thesis id, edge family, regime dependency, shared risk tags, correlated symbols, candidates in cluster, duplicate thesis flag, distinct edge flag, recommended portfolio expression, concentration warning, and governance recommendation.
