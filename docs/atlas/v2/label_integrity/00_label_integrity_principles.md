# Atlas V2 Label Integrity Principles

Atlas learning metrics are valid only when expected labels and actual labels are independently constructed. A high correlation is not evidence of learning when both labels come from the same field, score, heuristic, or provenance chain.

Label integrity reports are read-only audit evidence. They do not validate a strategy, promote an object, recommend an action, allocate capital, create candidates, create sleeves, create paper positions, or grant trading authority.

Unknown, incomplete, and low-provenance labels must remain visible. Missing actual outcomes must not be replaced with quality scores or expected labels.
