# Signal Quality Metrics

The label integrity report includes distinct-value counts, entropy, overlap ratio, shared provenance ratio, circularity score, and expected-vs-actual correlation.

Low entropy, low distinct-value counts, or dominant repeated labels indicate weak signal quality even when source provenance is independent. Homogeneous labels can make correlations unstable or misleading.

Recommendations in the report are audit guidance only and do not create validation, routing, allocation, recommendation, or execution authority.
