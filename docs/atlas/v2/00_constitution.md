# Atlas V2 Constitution

Atlas V2 is an adaptive behavior-change system that uses reality-driven corrections to improve future decisions.

The core loop is:

Decision -> Prediction -> Outcome -> Regret -> Behavior Change -> Better Future Decision

Atlas V2 exists to accumulate outcome-linked experience for attention-allocation decisions. It does not generate hypotheses, crawl YouTube, perform broad discovery, build a knowledge graph first, validate investment claims, create candidates, create sleeves, create paper positions, allocate capital, or authorize trading.

The primary scientific hypothesis is:

Atlas can improve future attention-allocation decisions through accumulated outcome-linked experience.

Core invariants:

- Historical truth is append-only.
- Every transition records timestamp, reason, and triggering object.
- Rejections and non-decisions are preserved.
- Unknown is distinct from failed.
- No consumer invents truth; consumers query recorded experience.
- Atlas V2 records learning evidence only and has no trading, validation, sleeve, candidate, paper-position, or capital-allocation authority.
