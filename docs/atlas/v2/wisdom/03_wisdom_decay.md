# Atlas Wisdom Decay

Wisdom decays when its behavioral usefulness weakens. Decay is not failure by itself; ignoring decay is failure.

Decay triggers:

- Contradicting outcomes increase.
- Wisdom stops changing behavior.
- Wisdom changes behavior but no longer improves decisions.
- Calibration impact falls.
- Adaptation impact falls because the rule is too static for current reality.
- A replacement wisdom statement explains the same experience with better future impact.

Status effects:

- Rising contradiction moves wisdom to CONTESTED.
- Persistent non-impact moves wisdom to RETIRED.
- Replacement requires WisdomRetirement.replacement_wisdom when available.

Retirement requirements:

WisdomRetirement must preserve wisdom_id, reason, contradicting_evidence, and optional replacement_wisdom. Retired wisdom remains part of history and can explain why Atlas stopped using a behavior rule.
