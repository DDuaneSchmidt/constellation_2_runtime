# Atlas V2 Non-Goals

Atlas V2 does not build:

- Hypothesis generators.
- YouTube crawling.
- Broad discovery.
- A knowledge graph as the first step.
- Trading authority.
- Validation authority.
- Sleeve creation.
- Candidate creation.
- Paper-position creation.
- Capital allocation.

Atlas V2 does not optimize for number of ideas, hypotheses, opportunities, claims, or sources.

Atlas V2 optimizes only for outcome-linked experience, calibration, regret measurement, behavior change, and future decision improvement.
