# Falsification Boundary

Contrarian theory informs falsification criteria. Primary failure modes, fragility conditions, and required falsification tests are copied into `ResearchHypothesis.contrarian_inputs` and `HypothesisFalsificationPlan`.

A falsification plan is a design artifact only. It states required tests, minimum sample requirement, baseline requirement, and falsification threshold. It does not run tests or record outcomes.

Forbidden outputs remain: experiment execution, cheap experiment fanout, candidates, sleeves, paper positions, trades, allocations, recommendations, validation authority, broker execution, autonomous execution, YouTube crawling, discovery, and live-market authority.
