# Claim-to-Hypothesis Generator Principles

Atlas V2 Claim-to-Hypothesis Generator V1 converts structured claims, mechanism classifications, mechanism registry context, and contrarian theory into testable research hypotheses.

The generator is a bridge from claim/mechanism memory to research design. It does not execute experiments, generate cheap experiment specs, create candidates, create sleeves, open paper positions, allocate capital, validate claims, recommend actions, submit broker orders, or grant live-market authority.

Every generated hypothesis must include a baseline comparison and falsification criteria. Contrarian theory is required to inform the falsification plan, especially failure modes and stress checks.

Runtime invariant: consumers do not invent truth. Consumers query the append-only Atlas V2 ledger and the verified runtime graph.
