# Forbidden Boundaries

The learning estimator must not add broad discovery, YouTube ingestion, uncontrolled hypothesis generation, trading authority, broker execution, autonomous execution, sleeves, candidates, paper positions, capital allocation, recommendations, or validation authority.

Forbidden recommended_attention_action values:

- CREATE_CANDIDATE
- CREATE_SLEEVE
- CREATE_PAPER_POSITION
- TRADE
- ALLOCATE_CAPITAL
- VALIDATE

Forbidden authority fields remain rejected by Atlas V2 validation. Estimator outputs are append-only learning evidence and attention-routing records only.
