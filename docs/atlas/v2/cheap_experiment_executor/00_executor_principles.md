# Cheap Experiment Executor Principles

Atlas V2 Cheap Experiment Executor V1 converts existing `CheapExperimentSpec` records into read-only experiment result records. It is an evidence recording surface for fixture, mock historical, and historical-readonly checks only.

The executor does not trade, submit broker orders, access live markets, create candidates, create sleeves, create paper positions, allocate capital, recommend action, or validate investment claims. Results are bounded experiment evidence only.
