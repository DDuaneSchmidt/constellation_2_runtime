# Forbidden Boundaries

V1 forbids:

- YouTube crawling
- channel crawling
- video downloading
- captions API usage
- autonomous ingestion
- broker execution
- autonomous execution
- trade advice
- recommendations
- candidate creation
- sleeve creation
- paper position creation
- capital allocation
- allocation surfaces
- validation authority
- profitability labels

External strategy claims remain untrusted claims. Cheap experiments may produce learning evidence, not trading authority.
