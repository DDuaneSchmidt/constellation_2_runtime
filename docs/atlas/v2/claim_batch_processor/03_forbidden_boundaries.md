# Forbidden Boundaries

Claim Batch Processor V1 may not grant or imply:

- trading authority
- broker authority
- allocation authority
- recommendation authority
- validation authority
- autonomous execution
- candidate creation
- sleeve creation
- paper position creation

Cheap experiment eligibility is learning workflow evidence only. Eligibility does not validate a claim, approve a strategy, recommend a trade, allocate capital, or create an executable object.
