# Forbidden Boundaries

Transcript Intake V1 must not add:

- channel crawling
- YouTube scraping
- caption APIs
- autonomous ingestion
- trading authority
- broker execution
- autonomous execution
- sleeves
- candidates
- paper positions
- capital allocation
- recommendations
- validation authority
- allocation surfaces

Performance claims, including claims such as `makes $10,000/month`, are `PERFORMANCE_CLAIM` segments only. They are never evidence and are never forwarded as candidate rule text.
