# Mechanism Registry Principles

Mechanism Registry V1 persists mechanism-level learning from Claim Batch Processor output. It stores durable mechanism families instead of isolated strategy names.

The registry is research, learning, and audit only. It may record, cluster, count, and report mechanisms. It may not validate a mechanism, recommend a trade, create candidates, create sleeves, create paper positions, allocate capital, use broker authority, or execute autonomously.
