# Input Contract

Mechanism Registry V1 reads ClaimBatchProcessor output from the Atlas V2 append-only ledger:

- ClaimBatch
- ClaimBatchRun
- ClaimBatchMetrics
- ExternalStrategyMechanism
- ExternalStrategyContrarianTheory
- ExternalStrategyCheapExperimentHandoff
